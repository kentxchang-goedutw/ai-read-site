# AI 閱讀素養適性評量系統 (AI Reading Literacy Adaptive Assessment System)

![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow.svg)
![TailwindCSS](https://img.shields.io/badge/TailwindCSS-3.x-blue.svg)
![Firebase](https://img.shields.io/badge/Firebase-11.x-orange.svg)
![License](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)

本系統是一款專為中小學設計的**免伺服器（Serverless）AI 輔助閱讀素養評量工具**。結合 Google Gemini 2.5 Flash 的強大生成能力與 Firebase 即時資料庫，教師只需上傳文本即可一鍵生成符合 PIRLS 架構的三階適性考卷，並享有 AI 自動化初閱與適性質性回饋功能。

本專案採用**單一 HTML 檔案架構**，完全無需建置複雜的後端環境，極適合課堂教學、公開授課與自主學習情境。

---

## 🚀 3分鐘快速安裝與佈署指南

本系統最大的特色為**無需購買主機空間**，利用 AI 工具的網頁分享功能，即可將修改好的程式碼轉化為親師生都能連線的雲端教學網址。

### 第一步：申請並設定 Firebase 資料庫
1. 前往 [Firebase Console](https://console.firebase.google.com/) 點擊「建立專案」。
2. 進入專案後，點擊網頁（標誌為 `</>`）圖示註冊一個 Web 應用程式。
3. 複製系統提供給您的 `firebaseConfig` 憑證內容（共 6 行關鍵設定值）。
4. 開啟本專案的 `AI 閱讀素養適性評量系統.html` 檔案，在程式碼頂端尋找關鍵字 `defaultFirebaseConfig`，將內含 `demo` 的預設 6 行程式碼改用您專案的憑證取代並存檔：
   ```javascript
   const defaultFirebaseConfig = {
       apiKey: "您的APIKey",
       authDomain: "您的專案ID.firebaseapp.com",
       projectId: "您的專案ID",
       storageBucket: "您的專案ID.firebasestorage.app",
       messagingSenderId: "您的傳送者ID",
       appId: "您的應用程式ID"
   };



5. **資料庫配置**：
* 開啟 **Firestore Database** 點擊「建立資料庫」，請務必選取「**以測試模式啟動 (Start in test mode)**」。
* 進入資料庫後切換至「規則 (Rules)」分頁，將代碼中的限制年份修改為 **100年後**（例如改為 `2126, 1, 1`）並點擊「發佈」，確保連線長期有效。


6. **身分驗證配置**：
* 開啟 **Authentication**，在「Sign-in method」分頁中啟用「**匿名登入 (Anonymous)**」功能。



### 第二步：利用 AI Canvas 免費發佈與生成教學網址

1. 開啟 **Google Gemini**（或支援網頁預覽編輯的 AI 平台），確保開啟了 **Canvas** 功能。
2. 對 Gemini 下達以下明確指令：
> *"給我一個空白的 HTML 網頁，網頁標題設定為「AI 閱讀素養適性評量系統」即可。"*


3. 當 Gemini 於 Canvas 視窗生成該網頁後，請切換至該視窗的原始碼（Code）編輯模式。
4. 將您在**第一步**中已經修改好 Firebase 憑證設定值的 `AI 閱讀素養適性評量系統.html` 完整原始程式碼複製，並直接**貼入 Canvas 中完整取代**原有的內容。
5. 按下 AI 視窗右上角的「**分享 (Share)**」按鈕，並發佈為共用網頁。
6. **完成！** 複製該專屬共用網址。之後無論是教師出題、還是學生作答，師生雙方皆使用這同一個雲端網址即可開始進行跨裝置教學！

## 📖 系統詳細使用說明

本系統劃分為**教師管理中心**與**學生測驗/查詢入口**兩大板塊，支援多裝置（手機、平板、電腦）響應式操作。

### 🛠️ 教師管理中心（初次登入預設密碼為：`tpet`）

```
[貼上文章 / 拖曳 PDF] ➡️ [AI 一鍵命題] ➡️ [手動微調校對] ➡️ [儲存並開放作答] ➡️ [AI初閱/手動發布報告]

```

1. **AI 智慧化三階命題**：
* 教師可直接貼上課程文本，或直接拖曳**多個 PDF 格式的課外文章**。系統內建的 PDF.js 解析器會自動提取純文字。
* 點擊「✨ AI 一鍵生成三階題庫」，系統會將文章自動發送給 Gemini，依照國際閱讀素養（PIRLS）框架，一鍵產出 **A（基礎擷取）、B（進階推論）、C（批判統整）** 三種不同難度的試卷（每階各含 10 題選擇題、2 題問答題）。


2. **視覺化彈性微調**：
* 生成完畢後，預覽區提供即時線上編輯面板。教師可手動微調 AI 出題的文字錯漏、調整選項順序，或重新指定選擇題的正確答案（系統預設會自動打散答案分佈）。
* 填寫題庫名稱（如：第七課 台灣翼手目生態）後，點擊「儲存至題庫櫃」。


3. **派送與進度控管**：
* 在「題庫櫃」中，教師可視課堂進度點擊「🚀 開放作答」或「停止派送」。只有點選開放作答的試卷，學生前端才會看得見。


4. **師 AI 聯合雙重評閱**：
* 切換至「👀 學生進度與批改」，教師可即時查閱已繳卷的學生名單。
* 點擊「🤖 AI 批改」，系統會依據文本、題目及學生寫的問答題答案，從*理解度*、*準確性*、*獨特性* 三個維度給予 0~20 分的細緻配分，並自動產出約 100 字的綜合評語與 50 字的進階閱讀建議。
* 教師亦可點擊「✍️ 手動」自行批改，或在 AI 初閱的基礎上進行二次手動分數修潤與評語改寫，校對無誤後點擊發送，診斷報告便會即時回傳給學生。

### 📝 學生挑戰與診斷中心

1. **參加測驗（實現差異化教學）**：
* 學生輸入姓名，並選取老師當下開放挑戰的題庫。
* 依據自身起步程度或學習進度，自由選取挑戰難度（等級 A、B 或 C）。這能落實落後學生有基礎題建立信心（扶弱）、資優學生能直接挑戰魔王題（拔尖）的教學願景。
* 作答時，網頁前端會提供乾淨的大字體閱讀鷹架。若有選擇題遺漏未寫，系統會在繳卷時發出紅色框線警告，避免學生粗心漏答。


2. **即時診斷報告查詢**：
* 學生隨時可在「查詢成績」分頁輸入自己的姓名，一鍵抓取所有已被老師審核通過的歷次評量報告。
* 報告中會以量化圖表（問答題與選擇題得分）和質性文字（老師與 AI 的聯合評語、下一步閱讀修煉建議）同步呈現，讓學生在課後也能明確掌握自主學習的方向。

## 🧠 適性題庫架構設計原理

本系統的命題邏輯與難度切分參考了國際閱讀素養調查（PIRLS）的四大閱讀歷程：

| 挑戰等級 | 核心素養層次 | 命題焦點與檢測目標 | 適用對象 |
| --- | --- | --- | --- |
| **等級 A**<br>

<br>🟢 基礎任務 | **擷取與直接推論** | 聚焦於文本表層訊息。檢測學生是否能找出文章中明確點出的細節、事實因果關係，幫助建立閱讀信心。 | 閱讀起步階段、低年級、或需進行補救教學之學生。 |
| **等級 B**<br>

<br>🔵 進階挑戰 | **詮釋與整合能力** | 跨段落隱含訊息連結。檢測學生能否歸納文章主旨、理解上下文文脈關聯、辨識作者的直接觀點與文章架構。 | 課堂常態教學、多數中高年級學生的核心評量。 |
| **等級 C**<br>

<br>🔴 終極魔王 | **比較與批判思考** | 跨越文本與先備知識整合。檢測學生評估文本真實性、批判作者意圖、提出獨立個人見解並進行論證的高階思維。 | 資優拔尖、高年級專題探究或深度閱讀思辨課。 |
